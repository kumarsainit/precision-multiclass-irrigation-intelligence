How close is this result

{{ experiment.final_model }} finished ahead of the runner-up by {{ "%.5f"|format(experiment.selection_margin) }} validation Macro F1. That margin is smaller than the fold-to-fold spread of cross-validation, so the three gradient-boosting models should be read as statistically indistinguishable on this dataset rather than as a ranking. The selection rule was fixed before the comparison and {{ experiment.final_model }} came first under it; it also carries the smallest train-to-validation gap of the three, which is the secondary reason to prefer it. Choosing either of the other two ensembles would have been defensible and would have changed the headline metrics by well under half a percentage point. {% if experiment.catboost_native_macro_f1 %} A separate run gave CatBoost its categorical columns directly instead of one-hot encoding them, which scored {{ "%.4f"|format(experiment.catboost_native_macro_f1) }} validation Macro F1 - no better than the shared encoding, so the shared encoding was kept for every model. {% endif %}
